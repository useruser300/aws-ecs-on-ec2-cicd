AWS ECS on EC2
CI/CD Pipeline

This project demonstrates a complete cloud-native deployment workflow using Amazon ECS, EC2 Container Instances, Docker, Terraform, and GitHub Actions.

The infrastructure is automatically provisioned with Terraform, container images are stored in Amazon ECR, and deployments are handled through a fully automated CI/CD pipeline.

Architecture Overview

  • GitHub Actions CI/CD Pipeline
  • Docker Image Build & Push to Amazon ECR
  • Amazon ECS Cluster running on EC2 Instances
  • Application Load Balancer for Traffic Distribution
  • Infrastructure Provisioning with Terraform
  • Containerized Nginx Application Deployment
